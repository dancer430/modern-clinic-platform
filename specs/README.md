# Specs

This directory is no longer the main entry point for change design.

For non-trivial changes in this repository, start with OpenSpec under:

```text
openspec/changes/<change-name>/
```

Use:
- `proposal.md` for change intent
- `design.md` for architecture and decision reasoning
- `tasks.md` for execution planning

For the repository-level workflow, see:
- `docs/change-governance.md`
